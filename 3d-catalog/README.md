# 3D-моделі E-Systems: Bluesun, Elecnova, ZOE, Golen

`index.html` — один файл з усіма 78 моделями чотирьох виробників (three.js, рушій і дані всередині, інтернет не потрібен).
Дві моделі Golen відкривають власні детальні сторінки: `sts.html` (комплект LES-261L130-PS / 241L120-PS зі STS)
і `psc.html` (LES-241L120-PSC: сонце + накопичувач + зарядка); three.js вбудований і в них, тож вони теж працюють без інтернету.

Перегляд у браузері: https://raw.githack.com/mischenkoa85-creator/Osbb/esystems-3d-catalog/3d-catalog/index.html

| Виробник | Моделей | Звідки дані |
|---|---|---|
| Bluesun | 24 | каталог Bluesun (гілка `ccr-d9838865-7deqb2`), вихідний код `ess3d-source-20261022` |
| Elecnova | 20 | каталог Elecnova (гілка `ccr-c1807205-gid4al`) |
| ZOE | 15 | каталог ZOE (гілка `ccr-d2720ae9-em99ku`) |
| Golen | 19 + 2 детальні сторінки | каталог Golen (гілка `golen-3d-catalog`) |

Дані моделей перенесені без змін. Окремі каталоги брендів на своїх гілках лишаються.

## Що на сторінці
- **Моделі** — панель з фільтрами «Тип», «Бренд», «Резерв», «Ринок» (EU / US — лише Bluesun).
- **Шафа / Система / Резерв** — як в окремих каталогах; на обладнанні стоять номери, підпис — лише для вибраного вузла.
- **Застосування** і **Технічні характеристики** — під моделлю.
- **Цін немає.** Прайс Elecnova і ціна з КП ZOE прибрані, бо каталог для клієнтів. Факти, які стояли в тих самих реченнях
  (склад у Роттердамі, гарантія 5 років), залишені.

## Спільне меню
Типи: шафи «все в одному»; шафи з гібридним інвертором / входом СЕС; інвертор + стійка; сонце + накопичувач + зарядка;
STS, EPS, мікромережа, комплекти з STS; контейнери з PCS; батареї DC без PCS; батарейні контейнери DC; PCS і гібридні
інвертори; станції PCS + трансформатор СН; готові системи 1–2 МВт.

Перенесені між групами, щоб один тип був в одному місці для всіх брендів:
- ZOE Z BOX-EV → «Сонце + накопичувач + зарядка»;
- Golen LES-261L130-PS → «STS, EPS, мікромережа, комплекти з STS»;
- батарейні контейнери DC (Elecnova B20FT5015, ZOE P 3400 / 5000 / 6200, Golen LBS-2508 / 5016) → «Батарейні контейнери DC»;
- Elecnova EPS — окрема позначка резерву «Перемикач EPS» замість «Bypass»;
- Golen LES-261L130-PS (шафа + бокова шафа зі STS) — у фільтрі «PCS + STS» з позначкою «STS у комплекті, ≤ 20 мс».

## Будова
- `engine/ess-cabinet.js`, `engine/page.css` — рушій з архіву `ess3d-source-20261022` (Google Диск, «Елементи СЕС / Блюсан»)
  з доповненнями: фільтр «Бренд»; логотип-напис з розміром і вирівнюванням; тексти без назви одного бренду;
  написи за брендом моделі; зсув колони пакетів; вкладка «Резерв» вимикається для мережевих PCS;
  власні тексти схеми резерву; позначки «EPS» і «мережевий PCS»; підписи номерів лише для вибраного вузла.
  Оригінал для порівняння — `tools/ess-cabinet.orig.js`.
- `brands/bluesun/configs.json`, `brands/elecnova/products.cjs`, `brands/zoe/products.cjs`, `brands/golen/*.cjs`
  (+ `brands/golen/pages/`) — дані брендів.
- `catalog.cjs` — спільне меню, перенесення між групами, вилучення цін.
- `site.json` — шапка, підвал і блок EMS E-Systems.
- `build.cjs` — збірка.

## Як оновити
```bash
cd 3d-catalog
npm install
node build.cjs          # index.html, sts.html, psc.html у цій папці
node build.cjs out --art   # окремо: копія для артефакту claude.ai
```
Модель додається у файл свого бренду; якщо в неї новий тип або тип резерву, його треба додати в `catalog.cjs`
(збірка зупиниться з повідомленням, якщо тип не має назви в меню). Збірка також повідомить, якщо в даних лишилася ціна.
