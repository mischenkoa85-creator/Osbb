# 3D-моделі Elecnova

`index.html` — один самодостатній файл з 20 моделями Elecnova. Рушій той самий, що в каталозі Bluesun
(гілка `ccr-d9838865-7deqb2`, `3d/index.html`): three.js і дані всередині, інтернет не потрібен.

- **Моделі** — панель з фільтрами за типом (шафи «все в одному», шафи з гібридним інвертором, STS / EPS,
  контейнери, батареї без PCS) і типом резерву (вбудований перехід, PCS + STS, EPS, потрібен PCS).
- **Застосування** — для чого модель, для кого, варіанти з позначкою «за Elecnova» або «оцінка», коли не підходить, що ще потрібно.
- **Система** — кілька шаф + шафа STS Elecnova (або СЕС для гібридних шаф) з імітацією відключення мережі.
- **Резерв** — схема «мережа / відключення / ДГУ»: що перемикає навантаження і де стоїть ATS.

Перегляд у браузері: https://raw.githack.com/mischenkoa85-creator/Osbb/ccr-c1807205-gid4al/3d-elecnova/index.html

Моделі схематичні: габарити — з даташитів, інструкцій і сторінок elecnova-ess.com; компонування — за фото з інструкцій
і рендерами. Де джерела розходяться (E233LS, B20FT5015LP-2), на сторінці показано обидва значення.
Ціни — з прайсу Elecnova (EXW Роттердам). STS / EPS — продукти Elecnova; ATS і ДГУ — стороннє обладнання.

## Як оновити

Дані моделей — `src/products.cjs`. Зібрати сторінку з каталогу Bluesun як рушія:

```bash
git show origin/ccr-d9838865-7deqb2:3d/index.html > /tmp/bluesun.html
node 3d-elecnova/src/build.cjs /tmp/bluesun.html 3d-elecnova/index.html
```
