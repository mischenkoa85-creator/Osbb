# 3D-моделі Golen

`index.html` — каталог 3D-моделей Golen Power в одному файлі. Рушій той самий, що в каталогах Bluesun
(гілка `ccr-d9838865-7deqb2`, `3d/index.html`) і Elecnova (`ccr-c1807205-gid4al`, `3d-elecnova/`): three.js і дані всередині, інтернет не потрібен.
Два вироби мають власні детальні сторінки, на які веде каталог:
- `sts.html` — комплект LES-261L130-PS / 241L120-PS (шафа АКБ + бокова шафа з STS і DC/DC) і системний STS на 4 шафи;
- `psc.html` — LES-241L120-PSC: сонце + накопичувач + зарядка електромобілів.

Що є на сторінці каталогу:
- **Моделі** — панель з фільтрами за типом (шафи «все в одному», шафи з СЕС-входом, комплекти з STS, зарядка, контейнери,
  батарейні контейнери, PCS, станції PCS + трансформатор) і типом резерву.
- **Застосування** — для чого модель, для кого, коли не підходить, що ще потрібно; позначки «за Golen» і «оцінка».
- **Система** — кілька шаф + STS або СЕС для шаф з гібридним інвертором, з імітацією відключення мережі.
- **Резерв** — схема «мережа / відключення / генератор»: що перемикає навантаження і де стоїть ATS.
- Номери стоять на обладнанні; підпис з'являється для вибраного вузла або під курсором. Опис вузла — у панелі поруч зі сценою.

Перегляд у браузері: https://raw.githack.com/mischenkoa85-creator/Osbb/golen-3d-catalog/3d-golen/index.html

Цін на сторінках немає навмисно: закупівельні ціни Golen — внутрішня інформація.

Точність: габарити, маса й характеристики — з паспортів, каталогів Golen 2026 (V1.4, V1.3), таблиць сайту golen-power.com,
посібників LES-H20 і LEI/LEG-500K-TT. Компонування — за розрізами й рисунками Golen, де вони є (LES-112W50-PS, LES-H20, LEI-500K-TT);
решта — схематично, і це написано під кожною моделлю. Де документи Golen розходяться, на сторінці наведено обидва значення.
Перелік джерел і розбіжностей — у документі проєкту «Перелік_3D_моделей_Golen_і_критерії_аудиту».

## Як оновити

Дані моделей — `src/*.cjs` (`lib.cjs` — спільні частини, `cabinets.cjs`, `h20.cjs`, `containers.cjs`, `pcs.cjs`, `links.cjs` — картки
детальних сторінок). Детальні сторінки — `src/pages/*.src.html`. Зібрати каталог з каталогу Bluesun як рушія:

```bash
git show origin/ccr-d9838865-7deqb2:3d/index.html > /tmp/bluesun.html
node 3d-golen/src/build.cjs /tmp/bluesun.html 3d-golen/index.html
```
