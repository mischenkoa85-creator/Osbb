# 3D-моделі ZOE

`index.html` — один самодостатній файл з 15 моделями ZOE (Shanghai ZOE Energy Storage Technology Co., Ltd, zoeess.com).
Рушій той самий, що в каталогах Bluesun (гілка `ccr-d9838865-7deqb2`, `3d/index.html`) і Elecnova: three.js і дані всередині, інтернет не потрібен.

Перегляд у браузері: https://raw.githack.com/mischenkoa85-creator/Osbb/ccr-d2720ae9-em99ku/3d-zoe/index.html

## Моделі

| Група | Моделі |
|---|---|
| Шафи «все в одному» | Z BOX-C PLUS 261-2H (125 кВт / 261 кВт·год), Z BOX-C 215-2H, C 215 SK, Z BOX-I 156-1H, Z BOX-EV (219 кВт·год + зарядка DC 180 кВт) |
| Гібридні шафи | Z BOX-C PLUS 261 Hybrid, Z BOX-C 100/120 2H |
| STS і мікромережа | Z BOX-STS 250/500/800, Z BOX-M 520 |
| Контейнери | Z BOX-P 1300-1H (1,26 МВт / 1,31 МВт·год), Z BOX-P 5000-2H, Z BOX-P 6200-2H, Z BOX-P 3400-2H |
| Батареї без PCS | Z BOX-H 418 2H |
| PCS | PCS 200B |

На сторінці кожної моделі є такі вкладки й розділи:

- **Шафа**: склад, двері, пакети, PCS, охолодження, пожежна безпека.
- **Система**: кілька шаф і Z BOX-STS, або СЕС для гібридних шаф.
- **Резерв**: що перемикає навантаження, коли зникає мережа.
- **Застосування**: позначки «за ZOE» або «оцінка».

## Джерела і точність

- Габарити, маса, склад: сторінки товарів zoeess.com, даташити та інструкції ZOE.
- Компонування:
  - C 261-2H, C 215-2H, P 1300-1H, P 5000-2H — за кресленнями з інструкцій;
  - решта моделей — за рендерами ZOE, схематично.
- Ціна є лише для P 5000-2H: 501 500 € FOB Китай, з КП ZOE від 22.10.2024.
- Де даних немає, на сторінці написано «немає в джерелі». Де джерела розходяться, показано обидва значення:
  - C 215-2H: габарит і маса;
  - I 156: глибина 1300 / 1600 мм (1600 — разом із кондиціонером);
  - P 3400-2H: енергія та маса;
  - P 5000-2H: маса 41 / 42 / 44 т;
  - H 418: маса;
  - C 261: діапазон напруги, шум, маса.
- Габарит Z BOX-STS у джерелі не вказаний: на моделі умовний, за пропорціями рендера.
- У P 6200-2H не вказана кількість пакетів.
- ATS і ДГУ — стороннє обладнання.

## Як оновити

Дані моделей лежать у `src/products.cjs`. Сторінку збирають з каталогу Bluesun, який слугує рушієм:

```bash
git show origin/ccr-d9838865-7deqb2:3d/index.html > /tmp/bluesun.html
node 3d-zoe/src/build.cjs /tmp/bluesun.html 3d-zoe/index.html
```
