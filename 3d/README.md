# 3D-моделі Bluesun

`index.html` — один самодостатній файл з усіма 24 моделями Bluesun (three.js і конфіги всередині, інтернет не потрібен).

- **Моделі** — кнопка вгорі: панель з фільтрами за типом (контейнери, системи, шафи, стійки, батареї, PCS),
  типом резерву (вбудований перехід, PCS + STS, Bypass, потрібен PCS) і ринком (EU / US).
- **Застосування** — блок під моделлю (і кнопка «Застосування»): для чого модель, для кого, варіанти застосування
  з позначкою «за Bluesun» або «оцінка», коли не підходить і що ще потрібно.
- **Резерв** — вкладка над моделлю: схема «мережа / відключення / ДГУ», де видно, що перемикає навантаження
  (гібридний інвертор, STS, Bypass або зовнішній PCS) і де стоїть ATS. Для батарей і PCS — сумісність за напругою.

Перегляд у браузері: https://raw.githack.com/mischenkoa85-creator/Osbb/ccr-d9838865-7deqb2/3d/index.html

Моделі схематичні: габарити — з даташитів Bluesun там, де вони є; компонування — за фото й рендерами.
STS, ATS, ДГУ й трансформатор — стороннє обладнання, якщо в джерелі не сказано інше; час перемикання STS/ATS — типовий, не дані Bluesun.
