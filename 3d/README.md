# 3D-моделі Bluesun

`index.html` — один самодостатній файл з усіма 24 моделями Bluesun (three.js і конфіги всередині, інтернет не потрібен).
Модель обирається списком «Інший товар» угорі сторінки або посиланням `index.html#<id>`.

Перегляд у браузері без завантаження:
https://raw.githack.com/mischenkoa85-creator/Osbb/ccr-d9838865-7deqb2/3d/index.html

Моделі схематичні: габарити — з даташитів Bluesun там, де вони є; компонування — за фото й рендерами (позначка точності на кожній сторінці).
