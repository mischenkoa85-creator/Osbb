# Монтаж СЕС Антарес

3D-послідовність монтажу дахової СЕС ТОВ МК «Антарес» (дах цеху 96 × 96 м і склад, 1 440 панелей 730 Вт, трикутник 41×41 з шарніром, модифікація Антарес, 15°).

Відкрити: https://raw.githack.com/mischenkoa85-creator/Osbb/montazh-antares/index.html

Джерела і збирання — у репозиторії elements-ses, папка `montazh-antares/`.
